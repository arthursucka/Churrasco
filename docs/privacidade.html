🍖 Política de privacidade do Churrasco

Última atualização: 23 de outubro de 2026

O Churrasco é um app para organizar churrascos entre amigos: convites, quem leva o quê, divisão de contas, chat e mapa no dia. Esta página explica quais dados ele usa e por quê.

Dados que coletamos

  • Conta: e-mail (ou a conta Google, se você escolher entrar com ela) e o nome que você mostra aos amigos. Usados para entrar no app, para seus amigos te encontrarem e para aparecer nos convites.
  • Churrascos: data, local, endereço, quem foi convidado, quem confirmou e o que cada pessoa vai levar.
  • Despesas e chave Pix: os valores que você lança e, se você cadastrar, sua chave Pix. A chave só aparece para quem participa de um churrasco com você e precisa te pagar. O app não faz pagamentos: ele só gera o código "copia e cola" para o app do seu banco.
  • Mensagens: o que você escreve no chat de cada churrasco.
  • Localização: só quando você toca em "Estou a caminho", a partir de 1 hora antes do churrasco, por até 2 horas. Ela continua sendo enviada com a tela bloqueada enquanto a notificação "Compartilhando sua localização" estiver aparecendo, e para quando você toca em "Parar" ou quando o tempo acaba. Só quem confirmou presença naquele churrasco vê. As coordenadas são apagadas quando a sessão termina.
  • Notificações: um identificador do aparelho (token do Firebase Cloud Messaging) para avisar sobre convites, mensagens e mudanças.
  • Falhas: relatórios de erro do app (Firebase Crashlytics), sem conteúdo das suas conversas.

Com quem compartilhamos

Seus dados só aparecem para as pessoas dos churrascos de que você participa e para quem você adicionou como amigo. Não vendemos nem compartilhamos dados com anunciantes. Usamos estes serviços para o app funcionar:

  • Google Firebase (login, banco de dados do chat e do mapa, notificações e relatórios de falha);
  • MongoDB Atlas (banco de dados dos churrascos);
  • Render (servidor da API);
  • OpenStreetMap (imagens do mapa; o app envia só a área do mapa que está sendo vista).

Por quanto tempo guardamos

Os churrascos ficam guardados para você consultar o histórico. Quando o organizador cancela um churrasco, o chat, o mapa e as contas dele são apagados. A localização é apagada ao fim de cada sessão de compartilhamento.
